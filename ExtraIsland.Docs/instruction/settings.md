# 全局设置

安装并启用 ExtraIsland 后，ClassIsland 设置界面会出现 **ExtraIsland** 设置分组，包含两个全局页面：

- **主设置**（`extraisland.master`）：管理模式开关、遥测与歌词接口状态。
- **值日表**（`extraisland.duty`）：管理全插件共享的值日生名单与轮换参数，详见 [值日表文档](/components/on-duty)。

## 主设置选项说明

### 歌词接口状态

页面顶部卡片会实时展示当前内置或联动歌词接口的运行状态：

| 显示状态 | 含义 |
| --- | --- |
| `未使用` | 当前未启用歌词功能，或检测到已安装 `LyricsIsland` 插件而禁用内置监听 |
| `Lychee` | 检测到已安装 `LycheeLib` 插件，歌词将通过 `LycheeLib` 获取 |
| `内置` | 已启用内置 LyricsIsland 协议 HTTP 监听服务并正常运行 |
| `错误` | 内置 HTTP 监听启动失败（例如端口被占用），卡片上方会显示具体错误信息 |

### 生活模式

- **说明**：启用不适用于课堂环境的个人向功能。
- **影响范围**：
  - 解锁组件 [Sleepy](/components/sleepy)。
  - 在 [当前活动](/components/live-activity) 组件设置中显示 **Sleepy 上报** 相关配置项。
- **生效方式**：修改此开关后需要**重启 ClassIsland** 方可生效。

### 允许遥测

- **说明**：允许插件通过 Sentry 采集未捕获异常与会话数据，用于定位崩溃与改进稳定性。
- **默认状态**：默认开启；调试构建（`DEBUG`）会自动禁用 Sentry 上报。
- **生效方式**：修改此开关后需要**重启 ClassIsland** 方可生效。

### 实验性功能

- **说明**：启用尚未完全打磨或仍在实验中的功能模块。
- **影响范围**：
  - 解锁组件 [双行容器](/components/dual-line-container)。
  - 在值日表设置页解锁 **自动跳过节假日** 开关。
  - 在安装 `IslandCaller` 时额外注册 **(实验性) 拉起 IslandCaller - 高级** 自动化行动。
- **生效方式**：修改此开关后需要**重启 ClassIsland** 方可生效。

> [!WARNING]
> 开启「实验性功能」后可能会遇到已知或未知的 Bug；如非测试需要，在稳定教学环境中建议保持关闭。启用实验性功能期间产生的实验模块异常请勿作为正式 Bug 反馈。
