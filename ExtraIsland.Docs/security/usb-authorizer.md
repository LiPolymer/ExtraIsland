# U 盘访问验证

`UsbDriveAuthorizer` 是 ExtraIsland 提供的 ClassIsland 访问认证提供方，允许使用物理 U 盘作为凭据解锁或验证操作权限。

> [!NOTE]
> 该功能依赖 Windows WMI / USB 设备监听机制，**仅在 Windows 平台注册并可用**。

## 两种验证模式

### 1. 硬件序列号模式（默认）

- 读取并记录 U 盘的硬件序列号（`SerialNumber`），并以 **SHA-256 哈希**形式保存在插件认证设置中。
- **优点**：无需在 U 盘中额外写入隐藏验证文件，拔插即验证。
- **局限**：部分劣质或山寨 U 盘、读卡器可能没有有效 S/N 或 S/N 异常；当遇到异常设备时，设置向导会弹窗提示 `此设备S/N异常,不能使用该设备!`。

### 2. 文件模式

- 在「使用文件模式」开关启用后，插件会在插入的 U 盘根目录下生成并读取隐藏凭据文件：
  ```text
  <盘符>\.verify.extraisland.nfo
  ```
- 若该文件不存在，会自动生成一个随机 `GUID` 写入其中，并存储其 **SHA-256 哈希**作为验证凭据。
- **适用场景**：U 盘无有效硬件序列号，或需要同一份文件凭据在备用存储设备上使用。

## 配置与使用步骤

### 绑定验证 U 盘

1. 打开 ClassIsland 设置中的访问控制 / 认证管理，添加 **U盘** 验证方式。
2. 按需决定是否开启 **使用文件模式**。
3. 点击 **设置验证存储器**（或切换文件模式开关）进入等待状态，界面提示 `现在插入U盘`。
4. 插入准备用作钥匙的 U 盘，完成后界面会显示 `完成!`。

### 日常解锁验证

- 弹出认证窗口后，直接插入已绑定的 U 盘即可自动触发识别与验证。
- 如果 U 盘在验证窗口弹出前就已经插在电脑上，可以点击 **已经插入?点此扫描** 按钮立即扫描当前已挂载的所有 U 盘。

## 注意事项

> [!WARNING]
> - **暂不支持多分区 U 盘**：如果 U 盘存在多个分区，可能导致设备识别或盘符匹配异常，请尽量使用单分区正规 U 盘。
> - **强烈建议保留备用密码**：建议在 ClassIsland 中同时配置常规密码等其他认证方式，避免因 U 盘丢失、损坏或格式化导致无法进入设置。
