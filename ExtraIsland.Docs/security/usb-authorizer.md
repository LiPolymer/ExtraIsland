# U 盘访问验证

`UsbDriveAuthorizer` 是 ExtraIsland 提供的 ClassIsland 访问认证提供方，允许使用物理 U 盘作为凭据解锁或验证操作权限。

> [!NOTE]
> 该功能基于 Windows 原生存储设备接口与窗口消息监听实现，**仅在 Windows 平台注册并可用**。不需要管理员权限，也不依赖 WMI 服务。

## 两种验证模式

### 1. 硬件序列号模式（默认）

- 通过 Windows 存储设备属性查询（`IOCTL_STORAGE_QUERY_PROPERTY`）读取 U 盘的真实硬件序列号（`SerialNumber`），并以 **带随机盐值的 HMAC-SHA256 哈希**形式保存在插件认证设置中。
- 支持传统 USB 存储设备以及现代 USB 3.x UASP 高速 U 盘 / 移动固态硬盘，同时原生支持**多分区 U 盘**（同一物理设备下的多个分区盘符会自动聚合）。
- **优点**：无需在 U 盘中额外写入文件，即插即验证。
- **局限**：部分劣质或山寨 U 盘、读卡器没有有效唯一硬件序列号（或返回全零、固定占位符、`NONE` 等无效值）；系统会自动识别并拒绝此类无效序列号，防止误用或被同型号设备绕过。遇到此类设备时，界面会给出明确提示并建议改用文件模式。

### 2. 文件模式

- 在「使用文件模式」开关启用后，插件会在绑定 U 盘的根目录下生成并隐藏凭据文件：
  ```text
  <盘符>\.verify.extraisland.nfo
  ```
- 若该文件不存在，会自动生成随机 256 位十六进制密钥写入其中，并为其设置 Windows `Hidden`（隐藏）属性，随后在配置中存储随机盐值与 HMAC-SHA256 哈希。
- 支持多分区 U 盘：绑定时会自动跳过 **EFI / 系统 / 恢复 / 隐藏分区**（GPT ESP、MBR `0xEF` 等）并优先选择常规数据分区写入 `.verify.extraisland.nfo`，绝不会向 EFI 分区写入新文件；验证时会优先读取数据分区，同时也兼容只读检索其他已挂载分区上的既有密钥文件。
- **适用场景**：U 盘无有效硬件序列号，或需要手动维护备用密钥文件的场景。

> [!CAUTION]
> 文件模式下的 `.verify.extraisland.nfo` 仅作为本地访问控制密钥令牌；任何能够读取并复制该隐藏文件到另一块 U 盘的人都可以模仿该文件凭据。请勿随意将该文件暴露或复制到不信任的设备上。

## 配置与使用步骤

### 绑定验证 U 盘

1. 打开 ClassIsland 设置中的访问控制 / 认证管理，添加 **U盘** 验证方式。
2. 按需决定是否开启 **使用文件模式**。
3. 可通过以下任意一种方式完成绑定：
   - **等待插入绑定**：点击 **等待插入U盘**（已绑定时显示为 **重新绑定（等待插入）**），随后插入准备用作钥匙的 U 盘即可自动识别并绑定。
   - **直接扫描已插入设备**：若 U 盘已经插在电脑上，直接点击 **扫描已插入U盘**；检测到单个 U 盘时会自动绑定，检测到多个 U 盘时可在下拉列表中选择目标设备后点击 **绑定所选U盘**。
4. 绑定成功后界面会以内联状态条显示已绑定设备的名称、盘符及当前验证模式。
5. 若后续切换了 **使用文件模式** 开关，需重新绑定 U 盘（或切回原模式）后才能保存认证设置。

### 日常解锁验证

- 弹出认证窗口后，直接插入已绑定的 U 盘即可自动触发识别与验证（内置短暂防抖与到达重试，以兼容多分区挂载时序）。
- 如果 U 盘在验证窗口弹出前就已经插在电脑上，可以点击 **已经插入？点此扫描** 按钮立即扫描当前已挂载的所有 USB 存储器。
- 对仅接入虚拟光驱（ISO）、VHD 或网络驱动器的挂载事件会自动忽略，不会误报验证失败。

## 兼容与注意事项

> [!TIP]
> - **向后兼容**：早期版本保存的无盐 SHA-256 哈希凭据（`Salt` 为空）以及旧版 `.verify.extraisland.nfo` 文件仍可正常验证通过；重新绑定后将自动升级为带盐 HMAC-SHA256 凭据。
> - **强烈建议保留备用密码**：建议在 ClassIsland 中同时配置常规密码等其他认证方式，避免因 U 盘丢失、损坏或格式化导致无法进入设置。
