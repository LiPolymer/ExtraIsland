# 展示标志

`FlagDisplay`（展示标志）用于将自动化行动 [设标志](/automations/#设标志) 写入的标志内容直接呈现在 ClassIsland 主界面组件栏中，实现自定义文本状态的动态展示。

## 工作机制

组件每秒随主计时器刷新一次，按以下优先级读取标志内容：

1. **内存标志**（运行期间临时设定的标志，优先级更高，可覆盖同名持久化标志）
2. **持久化标志**（保存在插件配置文件中的标志，重启后仍保留）
3. **占位文本**（当目标标志不存在或尚未设定时显示）

## 设置项说明

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **标志 ID** | 空 | 要监听并显示的标志键名，需与「设标志」行动中填写的标志 ID 一致 |
| **占位文本** | 空 | 当对应标志未被设置时显示的默认文本 |
| **启用动画** | 开启 | 关闭后内容变化时直接更新文本，不播放动画 |
| **启用切换动画** | 关闭 | 仅在开启「启用动画」时可用；开启后采用翻页切换动画，关闭则使用微闪渐变 |

> [!TIP]
> 你可以将「设标志 + 展示标志 + 读标志」组合使用：例如在不同时间段、不同课前提醒或外部事件触发时，通过自动化修改某个标志（如 `status = 自习中`），让岛上实时显示对应的状态提示。
