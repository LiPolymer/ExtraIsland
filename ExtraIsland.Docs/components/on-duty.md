# 值日表

`OnDuty` 用于在 ClassIsland 上展示今日值日生，并在设置中提供独立的 **全局 · 值日表** 管理页面（`ExtraIsland > 值日表`）。

> [!NOTE]
> ExtraIsland 的值日表定位为轻量、简洁的日常轮换工具，不会引入过于复杂的排班规则；如有更复杂的排班需求，请考虑使用专门插件（如 DutyIsland）。

## 组件设置

组件实例本身的设置位于对应课表/组件栏配置中，用于控制外观展示：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **紧凑模式** | 关闭 | 开启后以紧凑双行形式显示当前值日生列表 |

## 全局值日表配置（ExtraIsland > 值日表）

全局值日表配置保存在插件持久化目录的 `Persisted/OnDuty.json` 中，由组件、自动化行动「发送值日提示」与 SAI 数据块 `获取当前值日生` 共享。

### 时间与自动更新

- **上次更新**：展示最近一次执行值日轮换的时间戳。
- **自动时间抹零**：默认开启；每次自动轮换时将「上次更新」记为当天 `00:00:00`（`DateTime.Today`），确保次日一开机即可按“自然日”准时轮换，避免受开机时间漂移影响。
- **时间抹零**：手动将当前「上次更新」的时间部分清零至当天 `00:00:00`。

### 值日列表管理

- **当前索引 & 值日人预览**：顶部徽章实时展示 `当前索引 @ 当前值日生`。
- **行内编辑**：直接在表格中修改每个条目的 **索引**、**姓名** 或删除条目。
- **新建**：追加一名新值日生。
- **导入**：从纯文本文件（`.txt`）批量导入值日生名单，**一行一个姓名**，导入后会自动从 `0` 开始顺序分配索引并替换当前列表。
- **排序**：根据现有条目中的 `Index` 字段大小重新整理并规范化为 `0, 1, 2, ...` 连续索引。

### 轮换参数

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **索引** | `0` | 手动调整当前指向的值日生索引 |
| **循环** | 开启 | 列表遍历到末尾后自动归零从头开始轮换 |
| **轮换间隔** | `1` 天 | 每次轮换间隔的天数（最小 `1`） |
| **轮换方式** | `N人值日` | 支持以下两种模式：<br>1. **N 人值日**（可设置 `N=`）：每次展示从当前索引开始的连续 `N` 人，轮换时索引递增 `N`。<br>2. **内/外 双人轮换值日**：以两两配对形式展示「内:xxx 外:xxx」，轮换时索引递增 `1` 并按奇偶位交替内外岗位。 |

### 自动跳过节假日（实验性）

在 [主设置](/instruction/settings#实验性功能) 开启 **实验性功能** 后，值日表设置页会显示 **自动跳过节假日** 卡片：

- 开启后，执行日期轮换时会检查「上次更新」次日至今天之间的每一天。
- 判断逻辑内置周末检测，并结合第三方节假日 API（`timor.tech`）识别国家法定节假日与**调休补班日**：周末或法定假日不计入轮换，正常工作日与调休补班日照常轮换。
- 界面会同时展示 **节假日跳过历史**（上次跳过的节假日名称及索引变化）和 **即将跳过的节假日**。

> [!WARNING]
> 「自动跳过节假日」依赖联网访问第三方 API (`timor.tech`) 且属于实验性功能；若离线或请求失败，默认回退为按普通工作日处理（周末仍会跳过）。
