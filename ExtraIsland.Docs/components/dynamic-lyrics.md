# 动态歌词

`DynamicLyrics`（动态歌词）是一个独立的歌词展示组件，专注于在 ClassIsland 上轻量展示正在播放的音乐歌词。

## 主要特性

- **双协议兼容**：
  - 若安装并启用了 [LycheeLib](/instruction/integrations#lycheelib-歌词服务)（`ink.lipoly.ext.lychee`），直接通过 `LycheeLib` 获取实时歌词。
  - 否则自动启用内置的 **LyricsIsland 协议** HTTP 监听服务（`http://127.0.0.1:50063/component/lyrics/lyrics/`），接收 `lyric`（主行）与 `extra`（副行）字段的 JSON 推送。
- **主 / 副行分离展示**：可通过多个组件实例分别展示主行歌词与副行（如翻译/罗马音）歌词，互不干扰。
- **超时自动清空**：若超过 **10 秒** 未收到新的歌词推送，组件会自动清空当前歌词展示，避免残留。
- **翻页动画**：每次歌词更新时使用流畅的内容切换动画。

## 设置项说明

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **歌词类型** | `主行` | 可选 `主行`（对应主歌词 / `lyric`）或 `副行`（对应次级歌词 / `extra`） |

> [!NOTE]
> 如果你只希望在听歌时临时展示歌词、平时展示当前焦点窗口，也可以使用集成了歌词切换功能的 [当前活动](/components/live-activity) 组件。
