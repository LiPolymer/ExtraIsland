# 流畅时钟

`FluentClock` 为 ClassIsland 提供带有数字切换动画、冒号闪烁与整点强调效果的时钟组件。

## 主要特性

- **数字动画**：小时、分钟、秒数的十位与个位均独立动画切换。
- **可切换秒数显示**：支持显示 `HH:mm:ss` 或关闭秒数显示 `HH:mm`。
- **秒数小字号**：开启后秒数部分以更小字号紧随展示，层次更清晰。
- **整点强调特效**：整点到来时触发高亮强调动画。
- **时间源切换**：可跟随 ClassIsland 的精确时间服务（含时间偏移校准），也可强制读取 Windows 系统时间。
- **状态自愈对齐**：当 UI 线程短暂卡顿后恢复时，自动对各数位执行无动画静默校准，防止时间不同步。

## 设置项说明

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **精确到秒** | 开启 | 开启后显示秒数并关闭冒号闪烁；关闭后隐藏秒数，分钟分隔符每秒闪烁一次 |
| **启用翻页动画** | 开启 | 关闭后，所有数字切换动画将替换为微微闪烁效果 |
| **专注模式** | 关闭 | 仅在开启「启用翻页动画」时可用；开启后仅秒数改为微闪（分钟进位那一刻秒数同步一次翻页），避免频繁跳动分散注意力 |
| **使用系统时间** | 关闭 | 开启后直接读取系统时间 `DateTime.Now`，忽略 ClassIsland 的时间偏移设置 |
| **启用整点强调特效** | 开启 | 整点（`00` 秒）时触发整点强调背景动画；在设置中开启时会立即预览一次 |
| **秒数小字号** | 关闭 | 开启后秒数以较小字体显示 |
| **调整布局间隙** | `2` px | 调节小时、分钟、秒数面板之间的水平间距（范围 `0`–`24`） |

> [!TIP]
> 在教室大屏上长期展示时，如果担心秒数每秒翻页过于抢眼，建议保持开启 **精确到秒** 的同时启用 **专注模式**，或直接关闭 **精确到秒**。
