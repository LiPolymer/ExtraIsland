# 更好的倒计时

`BetterCountdown` 提供了比基础倒计时更丰富的格式控制、动画表现与到点提醒能力。

## 主要特性

- **多级时间精度**：支持精确到 **天**、**时**、**分**、**秒**。
- **全自定义文案**：支持同时自定义前缀、后缀以及天/时/分/秒单位分隔文本（默认示例：`现在 11天4时5分14秒 过去了`）。
- **隐零与无隙并置**：可自动隐藏数值为 `0` 的时间节点，或去除元素间内边距让排版更紧凑。
- **差一矫正**：在使用低精度（如仅显示到「天」）时自动对末位向上取整，更符合日常“还剩 X 天”的认知习惯。
- **专注模式与关闭动画**：可完整关闭动画，或在保留动画的同时将秒数替换为微微闪烁。
- **到点提醒**：倒计时归零时自动发送提醒通知，并支持自定义提醒模板。

## 设置项说明

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **文案设置** | 前缀 `现在`，后缀 `过去了`，单位 `天`/`时`/`分`/`秒` | 可分别修改前缀、各时间单位文本与后缀 |
| **目标时间** | 创建后 1 分钟 | 选择目标日期（`CalendarDatePicker`）与具体时分秒（`TimePicker`）；修改目标时间会重置已提醒状态 |
| **时间精度** | `分` | 可选：`天`、`时`、`分`、`秒` |
| **使用系统时间** | 关闭 | 开启后直接采用系统本地时间，无视 ClassIsland 精确时间偏移 |
| **无隙并置** | 关闭 | 开启后移除各文本节点间的默认间距（Padding 从 `2` 降为 `0`） |
| **差一矫正** | 开启 | 使用 `天`/`时`/`分` 精度时，将当前最高非精确末位自动 `+1`（向上取整） |
| **隐零** | 关闭 | 当选择的精度高于当前节点且该节点数值为 `0` 时自动隐藏（例如设为「秒」精度且剩余 `0` 天时隐藏天数节点） |
| **启用动画** | 开启 | 关闭后不再播放切换动画，适合低性能设备 |
| **专注模式** | 关闭 | 仅在开启「启用动画」时可用；将秒数动画改为微微闪烁，避免高频翻动 |
| **启用提醒** | 关闭 | 倒计时结束时通过 ExtraIsland 通知提供方弹出提醒 |
| **编辑提醒** | `{0} 已结束` | 自定义提醒正文；可用 `{0}` 指代 **前缀**、`{1}` 指代 **后缀** |

> [!TIP]
> 举例：若将 **前缀** 设为 `距离高考还有`，**后缀** 设为 `结束`，**编辑提醒** 设为 `{0} 已经到达目标时间！`，到点时即可触发自然语义提醒。
