# 当前活动

`LiveActivity`（当前活动）用于实时显示当前获得焦点（前台）的窗口标题，支持通过正则表达式清洗或隐藏特定窗口名，也可自动切换展示歌词，并支持在生活模式下向 Sleepy 上报当前活动。

## 主要特性

- **前台窗口捕获**：实时追踪当前活动窗口标题（在 Windows 上当焦点位于 ClassIsland 自身窗口时图标高亮提示）。
- **正则替换规则**：支持配置多条正则表达式，将窗口标题清洗为更美观的文本；若替换结果为空字符串且当前无歌词展示，组件会自动隐藏。
- **歌词自动切换**：支持接入 `LycheeLib` 或内置 `LyricsIsland` 协议；收到新歌词时自动切入歌词视图，10 秒无新歌词更新后自动切回窗口活动。
- **圆角与边距贴合**：支持自动同步 ClassIsland 主窗口圆角或自定义圆角，并可单独控制左/右两侧负边距收缩，更好地融入灵动岛边缘。
- **Sleepy 状态上报** *(生活模式)*：当主设置开启 [生活模式](/instruction/settings#生活模式) 后，可将当前活动实时推送到 Sleepy 服务。

## 设置项说明

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **左右间距** | 关闭 | 可独立切换左/右两侧是否应用 `-12px` 收缩边距，使其贴合岛端圆角 |
| **圆角** | 同步主窗口 | 开启时自动跟随 ClassIsland 主窗口圆角；关闭后可通过滑块自定义圆角半径（`0`–`30`） |
| **启用动画** | 开启 | 控制活动文本与歌词切换时的渐变动画 |
| **替换规则** | 空 | 可增删改多条规则，包含「匹配正则」与「替换为」两列；按列表顺序命中第一条匹配的正则后即执行替换 |
| **启用歌词** | 关闭 | 启用后接入 `LycheeLib` 或内置 LyricsIsland 监听服务（当检测到已安装 `LyricsIsland` 插件时此项自动禁用） |

### Sleepy 上报（仅生活模式可见）

在 [主设置](/instruction/settings#生活模式) 开启生活模式并重启后，设置页底部会显示 **Sleepy 上报** 配置卡片：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **Sleepy 上报** | 关闭 | 是否向目标 Sleepy API 上报当前展示的活动名称 |
| **目标 URL** | `https://sleepy.developers.classisland.tech/device/set` | Sleepy 服务端设置接口地址 |
| **密钥** | 空 | 接口鉴权 `secret` |
| **设备名** | `ExtraIsland Sleepy Interface` | 上报字段 `show_name` |
| **设备 ID** | `0` | 上报字段 `id` |
| **上传格式** | `{0}` | `app_name` 模板，其中 `{0}` 会被替换为经正则处理后的当前活动文本 |

> [!TIP]
> 在早期版本中使用过「忽略列表」的用户升级后，组件首次加载时会自动将旧的 `IgnoreListString` 按精确匹配正则 `^关键词$` 迁移到「替换规则」中（替换为空字符串）。
