# 档案信息

`ProfileInformation`（档案信息）用于读取当前 ClassIsland 课表档案中的开学周基准设置，并在岛上直观展示当前学期周次或单双周状态。

## 主要特性

- **动态计算周次**：根据 ClassIsland 主设置中的「单双周起始时间（`SingleWeekStartTime`）」与精确时间服务自动计算当前属于第几周。
- **两种显示类型**：支持在「周数」与「单双周」之间选择，或放置两个组件同时展示。
- **可定制每周起始日**：支持自定义每周的第一天是星期几（默认周一），避免跨周界线算错单双周。
- **简洁模式**：精简多余前缀或后缀文字，仅保留核心数字或「单/双」字样，方便放入紧凑布局或 [双行容器](/components/dual-line-container)。

## 设置项说明

| 设置项 | 默认值 | 显示示例（常规 / 简洁模式） | 说明 |
| --- | --- | --- | --- |
| **信息类型** | `周数` | `周数`：`第3周` / `3`<br>`单双周`：`单周` / `单` | 选择展示当前学期第几周或当前周的单双属性 |
| **简洁模式** | 关闭 | — | 开启后只显示核心周数数字或「单」/「双」 |
| **每周第一天** | `星期一` | — | 设置自然周的起始星期，影响周次跨周与单双周切换时机 |
