# 双行容器（实验性）

`DualLineContainer`（双行容器）是一个容器组件，能够将拖入其中的多个子组件自动拆分为**上下两小行**进行紧凑排布，有效利用岛上的纵向空间。

> [!WARNING]
> 本组件属于 **实验性功能**，需先在 [主设置](/instruction/settings#实验性功能) 中开启 **实验性功能** 并重启 ClassIsland 后才会出现在组件列表中。

## 拆分规则

向双行容器中添加子组件后，组件会自动按顺序均分为上下两行：

- 当子组件数量为偶数 `2k` 时：前 `k` 个位于上行，后 `k` 个位于下行。
- 当子组件数量为奇数 `2k + 1` 时：前 `k + 1` 个位于上行，后 `k` 个位于下行。

## 设置项说明

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **上行缩放** | `60%` (`0.6`) | 调整上半行子组件的缩放比例（`30%`–`100%`，步进 `5%`） |
| **下行缩放** | `70%` (`0.7`) | 调整下半行子组件的缩放比例（`30%`–`100%`，步进 `5%`） |
| **行间距** | `4` px | 调整上下两行之间的垂直空隙（`0`–`24`） |

> [!TIP]
> 双行容器非常适合组合显示紧凑型信息，例如上行放置 [档案信息（简洁模式）](/components/profile-information) 与星期/日期，下行放置 [值日表](/components/on-duty) 或 [展示标志](/components/flag-display)。
