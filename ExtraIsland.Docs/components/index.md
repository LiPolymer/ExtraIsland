# 组件总览

ExtraIsland 目前共提供 **10 个组件**，涵盖时间显示、倒计时、班级值日、名句展示、窗口活动与歌词显示，以及部分实验性与生活模式组件。

> [!IMPORTANT]
> 本插件的部分组件应用了动画效果，在部分较旧设备或集显低功耗设备上可能带来额外渲染开销。请根据实际硬件情况酌情在各组件设置中关闭动画效果。  
> **强制使用动画效果的组件**：[流畅时钟](/components/fluent-clock)（支持通过「关闭翻页动画」或「专注模式」改为微闪效果以减少视觉干扰）。

## 组件清单

| 组件名称 | 简介 | 启用前提 |
| --- | --- | --- |
| [流畅时钟](/components/fluent-clock) | 带翻页/微闪动画与整点强调特效的时钟 | 默认可用 |
| [更好的倒计时](/components/better-countdown) | 精确到秒、支持差一矫正、隐零、无隙并置与结束提醒 | 默认可用 |
| [值日表](/components/on-duty) | 展示当前值日生，支持紧凑双行模式 | 默认可用 |
| [名句一言](/components/rhesis) | 多来源、按权重随机获取名言诗词并可配置额外信息 | 默认可用 |
| [当前活动](/components/live-activity) | 展示前台窗口标题、正则替换、歌词切换与 Sleepy 上报 | 默认可用 |
| [动态歌词](/components/dynamic-lyrics) | 独立歌词展示组件，支持主/副行歌词切换 | 默认可用 |
| [档案信息](/components/profile-information) | 展示当前学期周次或单双周状态 | 默认可用 |
| [展示标志](/components/flag-display) | 实时显示由自动化「设标志」行动写入的标志文本 | 默认可用 |
| [双行容器](/components/dual-line-container) | 将多个组件自动拆分为上下两小行紧凑显示 | 需开启 [实验性功能](/instruction/settings#实验性功能) |
| [Sleepy](/components/sleepy) | 连接 Sleepy 实例并在岛上轮播设备在线状态 | 需开启 [生活模式](/instruction/settings#生活模式) |
