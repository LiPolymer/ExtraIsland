# 名句一言

`Rhesis`（名句一言）组件用于在岛上轮播展示古今诗词、哲理句子或日常一言，支持多内容源按权重随机抽取及丰富的展示过滤选项。

> [!NOTE]
> 本组件展示的内容均由第三方服务商 API 提供，插件不对第三方返回内容作任何担保。在教学环境中使用时，建议根据需要启用合适的内容源并配合 **排除列表** 过滤敏感词。

## 内置内容来源

组件支持同时启用多个内容源，每次刷新时按 **概率权重** 加权随机抽取一个来源进行请求（权重设为 `0` 等同于不参与抽取）：

| 来源 ID | 名称 | 默认启用 | 默认权重 | 来源附加配置 |
| --- | --- | --- | --- | --- |
| `jinrishici` | **今日诗词** | 开启 | `1` | 无 |
| `saintic` | **诏预** (`Saintic`) | 开启 | `1` | **接口路径**：对应 `https://hub.saintic.com/openservice/sentence/{路径}.json`，默认 `all` |
| `hitokoto` | **一言** (`Hitokoto`) | 关闭 | `1` | **附加查询参数**（不含 `?`，如 `c=i&c=k`）；全局字数限制会自动转换为 `max_length` 参数；内置 700ms 请求节流锁 |
| `dlystc` | **每日一句** (`dlystc`) | 关闭 | `1` | 无（提示：该接口有约 30s 的 CDN 缓存，短时间内频繁刷新可能返回相同句子） |

## 通用设置项说明

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **字数限制** | `0`（禁用） | 当获取到句子的正文长度超过该值时，会丢弃并自动重新抓取（最多尝试 6 次）；`一言` 来源会将该值作为 API 级 `max_length` 参数请求 |
| **刷新间隔** | `30.0` 秒 | 自动刷新时间间隔，设为 `0` 即禁用自动定时刷新 |
| **额外信息展示方法** | `同时展示` | 可选：<br>- **同时展示**：主标签显示正文，副标签同步显示作者/出处<br>- **分开展示**：先展示正文，再切换显示作者/出处 |
| **展示作者** | 关闭 | 将作者信息作为额外信息展示（未获取到则不显示） |
| **展示出处** | 关闭 | 将作品/出处标题作为额外信息展示（未获取到则不显示） |
| **额外信息展示时长** | `3` 秒 | 当展示方法设为「分开展示」时有效（最大不超过刷新间隔），控制切换后展示额外信息的时长；若设为 `0`（在「同时展示」且同时开启作者与出处时）会以两行网格分别排布作者与出处 |
| **启用动画** | 开启 | 关闭后不再播放文字切换动画，对低性能设备更友好 |
| **启用翻页动画** | 关闭 | 开启后正文切换使用翻页动画（额外信息沿用默认动画样式） |
| **排除列表** | 空 | 每一行填写一个需要屏蔽的关键词；当获取到的句子包含其中任意关键词时将忽略本次内容更新 |

### 导入排除列表

点击排除列表右侧的导入图标按钮，可从纯文本文件（`.txt`）一键导入屏蔽词（每行一个）：

- 单个文本文件大小上限：**1 MB**
- 排除列表总条数上限：**5000 条**（导入时会自动对已存在词条去重与空行过滤）
