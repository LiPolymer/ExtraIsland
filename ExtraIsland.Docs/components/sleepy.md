# Sleepy（生活模式）

`Sleepy` 组件允许你连接到现有的 Sleepy 状态接口实例，在 ClassIsland 岛上实时显示目标用户的在线状态及多设备正在使用的应用。

> [!IMPORTANT]
> 本组件面向个人桌面/生活娱乐场景，**默认隐藏**。请先在 [主设置](/instruction/settings#生活模式) 中开启 **生活模式** 并重启 ClassIsland，之后即可在组件列表中找到它。

## 主要特性

- **实时状态拉取**：按设定的更新间隔从 Sleepy `/query` API 获取状态名称与设备列表。
- **多设备信息轮播**：支持在主状态与各设备正在运行的应用信息之间定时轮播切换。
- **可配置动画**：支持关闭动画或启用翻页切换动画。

## 设置项说明

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **请求 API** | `https://sleepy.developers.classisland.tech/query` | Sleepy 实例的 `/query` 查询地址 |
| **更新间隔** | `5` 秒 | 向服务端拉取最新状态的周期（设为 `0` 时停止自动更新） |
| **轮播间隔** | `3` 秒 | 多设备/状态信息切换展示的时间间隔，设为 `0` 即关闭轮播 |
| **启用动画** | 开启 | 关闭后不再播放文字切换动画 |
| **启用翻页动画** | 关闭 | 开启后将内容切换动画替换为翻页效果 |
